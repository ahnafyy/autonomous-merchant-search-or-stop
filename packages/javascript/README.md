# agentic-shopping-search-or-stop

Browser-safe, dependency-free shopping decision utilities, checked against vectors
generated by the canonical Python implementation. It implements the recalled-search
formula used by the current study.

The host owns LLM calls, merchant tools, credentials, and purchase execution. This
package makes deterministic decisions; it never contacts a merchant.

```bash
npm install agentic-shopping-search-or-stop
```

## Recalled-search hook for LLM tool loops

Call `createRecalledSearchHook` after every seller reveal when the agent can retain
the best offer it has already seen. The hook implements:

```text
SEARCH iff feasible and E[max(best retained offer - next price, 0)] > inspection cost
```

Prices and API spend are integer USD minor units. Resource shadow prices may be
fractional numbers: `time_ms` is a duration in milliseconds whose shadow price is
minor units per second, and `tokens` is charged in minor units per thousand tokens.
The host calibrates next-price samples and remains responsible for dispatching tools,
enforcing actual budgets, and executing purchases.

```js
import { createRecalledSearchHook } from "agentic-shopping-search-or-stop";

const afterOffer = createRecalledSearchHook({
  priceSamplesMinor: [8900, 9400, 10200, 11100],
  shadowPrices: { time_ms: 8, api_calls: 2 },
});

const decision = afterOffer({
  currentBestMinor: 10000,
  nextInspectionResources: { time_ms: 12000, api_calls: 1, api_cost_minor: 18 },
  remainingBudget: { time_ms: 45000, api_calls: 3, api_cost_minor: 100 },
});

if (decision.action === "SEARCH") await callSellerTool();
else await buyBestRetainedOffer();
```

`decideRecalledSearch` exposes the same calculation without closing over the calibrated
samples. Both return feasibility, expected saving, the full inspection-cost breakdown,
net value, and reservation price so an LLM host can log or render its decision.

### ChatGPT/OpenAI and Claude tool registration

`recalledSearchToolSchema()` returns a portable `{ name, description, input_schema }`
object, and `runRecalledSearchTool()` executes that payload. Adapt only the outer tool
envelope for the chosen provider.

```js
import {
  recalledSearchToolSchema,
  runRecalledSearchTool,
} from "agentic-shopping-search-or-stop";

const schema = recalledSearchToolSchema();

// OpenAI Chat Completions-style registration:
const openaiTool = {
  type: "function",
  function: {
    name: schema.name,
    description: schema.description,
    parameters: schema.input_schema,
    strict: true,
  },
};

// Anthropic Messages-style registration:
const claudeTool = schema;

// When either model emits decide_recalled_search arguments:
const decision = runRecalledSearchTool(modelToolArguments);
```

The model is a caller, not the decision authority. Validate seller identity and the
same-product calibration sample before calling the tool, enforce actual tool permits
separately, and keep purchase authorization outside the model-tool loop.

## Study boundary

The current paper evaluates recalled adaptive stopping versus costed search-all. At
zero inspection cost search-all is better; small positive-cost intervals can be
inconclusive; material declared inspection costs can favor adaptive stopping. The
runtime hook is a formula implementation, not a claim that its inputs reproduce the
paper's frozen merchant data or checkout outcomes.

## Public API

- `decideRecalledSearch` — decide `SEARCH` or `STOP` after a retained-offer reveal
  using calibrated next-price samples and declared costs.
- `createRecalledSearchHook` — bind calibration samples and shadow prices once for a
  seller-tool loop.
- `recalledSearchToolSchema` / `runRecalledSearchTool` — register and execute the
  portable `decide_recalled_search` model-tool contract.

## Parity with Python

Python is the canonical implementation. This package is validated against
`artifacts/conformance/`, which Python generates; expected values are never duplicated
by hand. Python computes reservation prices and acceptance fractions in exact rational
arithmetic while JavaScript uses doubles, so numeric conformance is checked within the
tolerance recorded in those files. Integer results, such as the affordable-query
horizon, are compared exactly.

The vectors are generated under `artifacts/conformance/` by the Python build; the
JavaScript package never maintains a separate expected-value fixture.

The recalled-search hook is validated against vectors generated by the canonical Python
implementation. Study construction, replay, and bootstrap remain repository-side
research tooling rather than this runtime API.

## Production boundary

The public runtime surface is `decideRecalledSearch`, `createRecalledSearchHook`,
`recalledSearchToolSchema`, and `runRecalledSearchTool`. The package contains no
merchant clients, provider SDKs, credentials, or network calls. Your host must provide
trustworthy same-product calibration samples and remain the sole authority for external
tool calls and purchases.
